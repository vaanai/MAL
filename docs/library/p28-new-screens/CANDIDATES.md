## Capacity convention used below

Depth Qeff = (quote_reserve PRE-trade + V) / 1e9 SOL, with V about 17.58 SOL on boosted pools (tools/arena_tape_schema.md: PumpSwap reserves are PRE-trade, V is the stored PRE-trade value; verified there, not re-derived here). One-way entry impact of stake s is s / (Qeff + s). A pool sitting at the V floor has Qeff about 17.6, which gives one-way 1.4% / 2.8% / 5.4% at 0.25 / 0.5 / 1.0 SOL (round trip about double; zero-fee constant product returns the stake exactly, so the cost is the fee plus the price move between legs). Capacity line = decisions/day x stake x net edge needed, where net edge needed = about 2.4% cost floor plus the impact leg plus a margin.
