- **AM1:** each decision key (pool|slot|post sqrt price) is mapped to its row i in the full `load_exploration` D, then priced with `dbc_screen.resolve(m10, P, [i], D, comp_slot, lat_in, 1.9)`. The `price_cell` lines follow: `round_trip` and then `arena_stack.fail_legs`. For a set with no fixed-cost item, the result is checked equal to `dbc_screen.price_cell`.
- **AM2 refusals.** Counts are printed for each.
  - bad_state: priced on D with bad_row zeroed.
  - completed_before_entry and no_state: -160,000 lamports.
  - block_edge and bad_hour: excluded.
  - key not found: full loss of 250,000,000 + 160,000 + 2,039,280 lamports. If more than 1% of C1 is not found, the result is NOT_DECIDABLE.
- **Edge rules the ruling does not spell out, declared here before the run:**
  - (a) a bad_state decision still refused on the zeroed D (non-finite carried L at entry or exit) is a FULL LOSS, counted as `bad_state_still_refused_full_loss`;
  - (b) any other refusal reason is a FULL LOSS (`other_refusal`; none is expected for a single index);
  - (c) a key that maps to two rows of D is priced at the last such row and counted (`key_duplicate`);
  - (d) fixed-cost items carry the same value under both fail models, because no filled send fails.
