**Is it worth it?** Recommendation: **no, not now.**
- Q40 v1 is a strict subset of Q50 on the same pools with the same 330 s exit (EXP-024 Am.10 disclosure: every v1 trigger pool is a Q50 trigger pool). It adds 1 to N and best-of-siblings selection (Am.3 item 8 (e)), and little new information. It cannot add live capacity either: its trades are Q50's or s1's trades on the same pools, so a second live book would double the stake per pool and the impact.
- v2 changes the exit, not the entry, so it is the only sibling with different information. But at `1f7a89c` its window would end at 11-06 (at most 8 dates from a 10-29 clock, at a lower trigger rate than Q50), so a NOT_DECIDABLE that costs N + 1 is the likely end, and it would compete with s1 for the 11-01 to 11-05 review and memory budget on the critical path.
- If a v2 sibling is wanted, the cleaner route is a pre-registered v2 book at the 11-06 boundary on an S\*-style base for `1f7a89c`, decided before any s1 or Q50 read verdict, and only after s1's registration is safe. That is a separate decision for the manager, not part of this PR.
